# Empty But Live

Portfolio URL: https://austinpavia.dev

## Chosen Stack

I chose a plain-code portfolio hosted on Vercel with a custom domain.

- Build: HTML, CSS, and JavaScript
- Host: Vercel
- Domain: `austinpavia.dev`
- Backend at launch: not needed yet

## Rationale

I chose plain code because my portfolio needs to prove that I can build and ship real web work, not just arrange content in a builder. It is still small enough for me to maintain: static pages, real project sections, screenshots, links, and contact actions. I did not choose a no-code builder because I want the repo and code quality to be part of the proof. I did not choose a heavier framework because the portfolio does not need dynamic data or authentication at launch.

## Alternatives Considered

| Option | Why I Did Not Choose It |
| --- | --- |
| No-code builder | Fast, but it would not show my ability to maintain a real codebase. |
| Plain HTML/CSS/JS on a free host | Chosen because it is maintainable, free, and enough for the portfolio. |
| Full framework like Next.js | Powerful, but unnecessary for a mostly static portfolio right now. |
