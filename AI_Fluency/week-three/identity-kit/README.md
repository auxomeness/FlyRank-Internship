# Portfolio Identity Kit

Portfolio: https://austinpavia.dev

## Fonts

| Use | Font | Source | Why |
| --- | --- | --- | --- |
| Headings | Familjen Grotesk | Google Fonts | Clean, confident, technical without looking decorative. |
| Body/UI | Inter | Google Fonts | Readable, neutral, and familiar for product-style interfaces. |

## Palette

| Role | Hex |
| --- | --- |
| Main color | `#2E9EFF` |
| Near-black text/background | `#040508` |
| Near-white background/text | `#F8F8F5` |
| Muted supporting text | `#D8D8D8` |

## Logo / Favicon

File: `identity-favicon.svg`

The favicon is a simple `A` monogram on near-black with one blue underline. It is intentionally quiet: enough to make the portfolio feel finished, not enough to compete with the project work.

## Two-Line Style Note

Use Familjen Grotesk for headings and Inter for body/UI text. Palette: `#040508`, `#F8F8F5`, `#D8D8D8`, and `#2E9EFF`.

The mood is calm, technical, and restrained so the project screenshots, backend proof, and GitHub work stay louder than the frame around them.

## AI Workspace Standing Instruction

Use this identity kit when helping me write or build portfolio sections. Keep typography simple, use the four-color palette consistently, and reject visual ideas that make the design more memorable than the work.
