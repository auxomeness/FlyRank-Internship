## Identity Kit

### Fonts

Heading: Familjen Grotesk

Body: Inter

Mono labels: Martian Mono

Reason: the fonts feel technical and clean without looking decorative. They match a backend-focused portfolio because the type stays quiet and lets project evidence carry the page.

### Palette

| Role | Hex |
| --- | --- |
| Near-black background/text | `#040508` |
| Near-white background/text | `#F8F8F5` |
| Muted body text | `#D8D8D8` |
| Single accent | `#2E9EFF` |

### Logo / Favicon

File: `identity-favicon.svg`

The mark is a simple `A` on near-black with one blue underline. It is intentionally small and quiet so it brands the site without competing with the project screenshots.

### Two-Line Style Note

Use Familjen Grotesk for confident headings, Inter for readable body text, and Martian Mono only for short labels. Keep the palette near-black, near-white, muted gray, and one blue accent so the work screenshots are the loudest visual element.

I rejected the idea of an abstract glowing backend/network hero image. It might look modern, but it would not prove anything about my work. A clean headline followed by real project screenshots is stronger for the audience I want to convince.

## AI Workspace Style Instruction

When helping build this portfolio, keep the design calm and consistent. Use the claim, content map, fonts, palette, favicon direction, and image decisions above. Do not add decorative generated images where a real screenshot or plain section would prove the work better.
