# Draw the Path - Portfolio Sitemap

This folder contains the Week 1 AI Fluency "Draw the Path" deliverables.

## Proof Statement

I want my portfolio to prove that I am a backend-focused full-stack developer who can build clean, reliable, real-world systems with strong UI/UX awareness.

## One Main Action

I want visitors to contact me or view my GitHub projects.

## Sitemap

The sitemap is intentionally small:

```text
Home
- Hero
- Featured Work / Proof
- About
- Contact
```

Every section earns its place against the proof statement:

- Hero states who I am and gives the visitor a clear GitHub/contact action.
- Featured Work proves the claim through APoS, LUMEN, EXPY, and CodeGuard AI.
- About gives short credibility context without becoming a biography.
- Contact supports the main action directly.

## AI Workspace Used

The assignment requested Claude, but I used Codex as my configured AI project workspace instead.

Codex was given the proof statement, one main action, and tutor-style instruction to challenge weak decisions and keep the sitemap focused.

See:

- `codex-project-context.md`
- `pressure-test.md`

## Change After Pressure Test

I will make the Featured Work section proof-based instead of project-name-based by showing the problem, stack, backend role, and system behavior for each project.
